# Kaede's Pizzaria

A pizzeria website built to practice HTML, CSS, JavaScript, SQL, and other technologies, with the goal of eventually offering it to real clients.

## About the Project

Kaede's Pizzaria is a personal web development project focused on building a functional and visually appealing website for a pizzeria.

This project is part of my journey to improve my programming skills, explore new technologies, and develop practical experience by creating a real-world style application.

## Technologies

- HTML
- CSS
- JavaScript
- SQL (planned for future development)
- Other technologies as the project evolves

## Goals

- Build an interactive pizzeria website.
- Improve my front-end development skills.
- Implement shopping cart and checkout features.
- Explore databases and back-end development.
- Turn this project into a solution that could eventually be offered to real clients.
